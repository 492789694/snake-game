    🎋 竹知了 · 玩法与原理

    🧸 这是什么

    竹知了是中国传统发声玩具：一截竹筒，一端蒙上竹膜或牛皮纸，膜中央开小孔； 棉线穿过小孔，一头系在筒内的横签上，另一头系在竹柄上。 搓动/甩动竹柄，棉线绞动带动竹筒绕线轴高速旋转， 棉线与膜孔边缘摩擦 → 膜振动 → 竹筒共鸣放大，发出类似蝉鸣的“哇哇”声。

    🎮 怎么玩

    • 🖐 搓动：按住画面（或按住竹知了附近）快速左右来回搓 —— 搓得越快转得越快，叫得越响。
    • 🤏 双指拧转（触屏）：两根手指在屏幕上像搓木柄一样拧。
    • 📳 摇一摇：摇动手机，点“📳”按钮开启（iPhone 需授权）。
    • 🎥 摄像头手势：点“🎥”开启，单手在镜头前快速左右摆动，或双手做“搓手”动作。
    • ⌨️ 键盘：按住 空格 / ← / → 自动搓动。
    • 🔭 视角：双击画面或右键拖动旋转视角；点底部“模式”按钮切换，视角模式下可拖动旋转、滚轮缩放，细看竹节与结构。

    🔊 声音与物理（和真玩具一样）

    • 搓动给竹筒一个初始角速度，之后受空气阻力（∝转速²）与棉线摩擦影响自然衰减 —— 不搓就会慢慢停下。
    • 音调、响度由实时转速连续驱动：转速越高，摩擦频率越高 → 音调越高、越响；转速降下来，声音自然衰弱消失。
    • 转速快时离心力把竹筒甩起绕圈（锥摆），转速慢时垂下来摇摆。
    • 声音全部由 Web Audio API 实时合成（锯齿波 + 摩擦噪声 + 竹筒共鸣滤波），没有任何录音文件。

    🏆 挑战规则

    • 转速里程碑：120「初鸣」→ 300「蝉声渐起」→ 600「烈日蝉鸣」→ 900「群蝉齐鸣」→ 1200「震翅狂鸣」→ 1500「竹蝉之王」，首次达到有加分。
    • 连续鸣叫：持续鸣叫每 4 秒倍率 +1（最高 ×8）；中断超过 1.5 秒倍率归零。
    • 今日挑战：冲上 900 RPM / 连续鸣叫 20 秒，各奖 1500 分。
    • 纪录：最高分、最高转速、最长连鸣保存在本机浏览器中。

    构造与发声原理参考：百度百科《竹知了》、国立中山大学物理演示《竹蟬的聲學》、旋转气鸣器（bullroarer）声学研究 —— 音调随转速升高。
